# Provider-free browser design lesson

This self-contained lesson uses the browser-runtime redesign to practice
deep-module reasoning. It is educational material, not an implementation plan
or evidence of Formal conformance.

## Start here

1. Read the [mission](MISSION.md).
2. Open [Designing the Browser Executor](lessons/0001-designing-the-browser-executor.html)
   in a browser.
3. Use the [deep-module scorecard](reference/deep-module-scorecard.html) to
   review an interface proposal.
4. Consult the [resources](RESOURCES.md) for the decision and design sources.

The HTML files share [`assets/course.css`](assets/course.css) and are intended
to work directly from the repository without a build step.
