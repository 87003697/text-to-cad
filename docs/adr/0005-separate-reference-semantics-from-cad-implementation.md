# Use a lightweight Agent-authored Reconstruction Spec

When explicitly enabled, mesh-to-cad asks the Agent to create a mutable JSON Reconstruction Spec from the inspected input mesh and its Canonical Reference before initial CAD authoring, then to keep using and correcting that working document during repair. Components, Features, and directed Relations share human-readable IDs; `part_of`, `depends_on`, and `affects` are reserved Organizational Relations, other non-empty kinds remain open Constructive Relations, and description, certainty, and evidence stay optional. The Spec ignores user semantic hints, describes reference semantics rather than CAD operations, and deliberately remains outside Workspace authority, revision history, Code Map, and Conformance until its practical value is proven.
