# meshshot

`meshshot` owns the versioned camera, lighting, depth, composition, and
downsampling profile for formal canonical residual previews. Its Python API
orchestrates one batched headless-browser render; its JavaScript core renders
all eight fixed views without fitting either input mesh.

The package is framework-agnostic. Production skills vendor it instead of
importing code from sibling skills. Large geometry payloads cross the sealed
same-origin browser route instead of the automation protocol's structured-value
boundary; camera, composition, and pixel semantics remain profile-owned.
